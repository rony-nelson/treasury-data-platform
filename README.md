# Treasury Data Platform

Portfolio project that simulates the data platform of a bank treasury: bank reconciliation,
cash flow, fixed income (LFT, LTN, CDB), Selic settlement, FX and an AI agent that answers
questions about cash. **All data is synthetic, generated by scripts.**

The goal is to show, step by step, how CI/CD makes financial data work safer:
every change goes through a pull request, automated tests, linting and, later, controlled deploys.
